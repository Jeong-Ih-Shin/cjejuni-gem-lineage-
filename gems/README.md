# Genome-Scale Metabolic Models (GEMs)

86 strain-specific genome-scale metabolic models in SBML format, reconstructed
with gapseq v1.2 (commit 6c2ff0e9; `doall`, default parameters).

The SBML files (~527 MB total) are **not tracked by git** due to size.
Download from Zenodo (DOI to be added upon publication) and place in this
directory:
