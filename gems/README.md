# Genome-Scale Metabolic Models (GEMs)

86 strain-specific genome-scale metabolic models in SBML format,
reconstructed with gapseq v1.2 (commit 6c2ff0e9, `doall`, default parameters).

The SBML files are archived on Zenodo (DOI: 10.5281/zenodo.21886583).
Download `gems.zip`, extract it into this directory, and run the
downstream analyses via `bash run_all.sh` from the repo root.

Expected files: `cmccj_NNNN.xml` (86 files total).
